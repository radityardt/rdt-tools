What this is

This tool is run privately by its owner for their own use. It is not offered to the public.

Google data it accesses

Only the Google Drive scope drive.file: the files this tool creates in the owner's Google Drive. It cannot see any other files in that Drive.

How the data is used

To upload files, create share links for them, and download them again for further editing. Nothing else.

Sharing

Google user data is not sold, shared with third parties, or used for advertising.

Storage

Working copies are kept on the owner's private server and deleted after processing. The access token is stored only on that server.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
